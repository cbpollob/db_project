# CineClick - Figma UI/UX Design Prompts

## 🎨 Simple UI Design Prompts for Figma

Use these prompts with Figma AI, Galileo AI, or as design guidelines for creating your CineClick mobile app screens.

---

## 📱 App Theme & Style Guide

### Master Prompt (Use this first to set the design system)

```
Create a modern, clean mobile app design system for a movie streaming app called "CineClick".

Design System:
- Style: Dark mode, cinematic, minimal
- Primary Background: #0f2027 (dark navy)
- Secondary Background: #0c0f12 (darker card)
- Accent Color: #00c6ff (cyan blue)
- Secondary Accent: #fbbf24 (golden yellow)
- Text Color: #e2e8f0 (light gray)
- Muted Text: #9aa6ae (gray)
- Font: Inter or SF Pro
- Border Radius: 12px for cards, 10px for buttons
- Shadows: Subtle dark shadows

Create the following components:
1. Button styles (primary, outline, small)
2. Input fields (text, password, search)
3. Card component for movie thumbnails
4. Navigation bar
5. Star rating component
6. Tab bar for bottom navigation
```

## 🎨 Design Tips for Figma

### Setting Up Your Figma Project

1. **Create a new Figma file** named "CineClick Mobile App"
2. **Set up frames** for iPhone 14 Pro (393 x 852)
3. **Create a color styles page** with all the colors above
4. **Create components** for reusable elements (buttons, cards, inputs)

### Using Figma AI

If using Figma AI or similar tools:
1. Copy the prompt for each screen
2. Paste into the AI design tool
3. Adjust and customize the output
4. Export assets as needed

### Manual Design Approach

1. Start with the **Design System prompt** to create components
2. Build screens using those components
3. Maintain consistency across all screens
4. Use Auto Layout for responsive designs

3. **Create each screen** using the individual prompts
4. **Link screens** using Figma's prototyping feature
5. **Test the flow** in Figma's presentation mode
